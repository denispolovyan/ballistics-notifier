команди в контрольний телеграм чат:

stop - зупиняє програвання звукового сигналу на необмежений час. в history.txt спрацювання записуються
stop N - зупиняє програвання музики на певну кількість часу. N - кількість хвилин. в history.txt спрацювання записуються. також скидає дію безстрокової команди stop 
start - відновлює програвання звукового сигналу при знаходженні ключових слів

// ———————— //
час програвання, ключові слова і канали до відстеження можна змінити у файлі config.py

// ———————— //
файл sounds/ballistics.mp3 замініть на ваш звуковий сигнал
